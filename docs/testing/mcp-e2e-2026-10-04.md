## Isolation and process boundaries

Each runner selects a fresh absolute OS temporary directory.
`mcp_process.py` creates an empty working-directory `.env`, private home/cache directories, and an
allowlisted child environment. `DATABASE_URL=sqlite:////.../maverick.db` and
`CACHE_SQLITE_PATH=/.../maverick-cache.db` point inside that disposable state.
`CI`, `GITHUB_ACTIONS`, Redis settings, proxy variables, and credentials are not
inherited. Lifecycle JSONL captures sanitized configuration, commands, versions,
timestamps, ports, and process exits. Keys are redacted.

The normal launch commands are absolute `.venv/bin/python -m
maverick.server.app --transport stdio` and the same command with
`--transport http --host 127.0.0.1 --port <unused-port>`. The harness uses the
official MCP SDK across pipes or the live `/mcp` HTTP endpoint. It captures raw
STDIO JSON-RPC separately from stderr. No `build_server()` call or in-memory
FastMCP client establishes any transport result in this report.

Native PostgreSQL 17.9 and Redis 8.10.2 used disposable directories and separate
ports. The user's existing services on 5432 and 6379 were never targeted.
Destructive tools ran only against disposable state. No normal portfolio,
watchlist, journal, database, Redis instance, or client configuration was changed.

## Defects, regressions, and review

1. Unknown watchlist IDs could create orphan items or report misleading removal
   success. Validate existence inside the write session. Focused tests failed
   before the change, passed afterward, and both transport reruns pass.
2. Risk/sizing calls accepted negative/nonfinite numeric inputs. Reject invalid
   values before arithmetic while retaining existing zero-risk/equal-stop
   behavior. The regression includes NaN/Infinity and invalid finite values;
   MCP returns structured errors. Financial ledger arithmetic remains Decimal.
3. A live research response reached synthesis with a dictionary score, causing
   `unsupported operand type(s) for +: 'float' and 'dict'`. The original exact
   model JSON was not captured, so its shape is an inference, not claimed raw
   evidence. A synthetic score-object reproduction failed 40 cases before repair.
   Normalize scalar/string/`{score: ...}` values and reject invalid/nonfinite or
   out-of-range scores through the existing marked fallback. Focused research
   checks pass, both transport regressions pass, and all three live research
   reruns pass. Later live evidence includes model output.

Independent subagent review found no actionable issues in the three product
fixes; an independent 140-test portfolio/research run passed. Protocol review
also tightened harness assertions so empty success payloads cannot pass optional
tools and the application-client test checks exact status, ID, count, and name.
Preserved diagnostic evidence distinguishes product defects from SDK decoder,
readiness, timeout-order, path-resolution, proxy, and sandbox harness/environment
failures. No unrelated refactor or dependency upgrade was made.

The full offline invocation selected 1,774 cases: 1,761 passed, seven import
contract tests failed because `lint-imports` was absent from the subprocess
PATH, and six artifact tests skipped without artifact paths. The product source
did not change afterward. The seven environment failures passed with
`.venv/bin` on PATH, and the six artifact cases pass with explicit wheel/sdist
paths. A redundant full rerun was interrupted under host contention; its partial
log is retained. These records must not be described as one clean full-suite
invocation. Initial sandbox socket denials and inherited proxy configuration

The duplicate run also exposed
`tests/portfolio/test_service_concurrency.py::test_concurrent_processes_preserve_every_acknowledged_share[sqlite]`
failing at its 15-second worker-startup barrier. An exact rerun failed there
again (15.34 seconds); no concurrent write or final balance assertion was reached.
This is an unresolved worker-readiness failure, not a passing test. The same source passed this
case in 1.71 seconds in the earlier completed run, and actual MCP concurrent
mutations pass on both transports; those results do not close this failed
regression. No deadline was enlarged to obtain a pass. The original test does
not drain child initialization errors from its queue when the barrier fails.
An instrumented reproduction therefore recorded worker stages, queued errors,
and Python/native stacks before terminating its own workers. Both workers were
still importing FastMCP/MCP/Pydantic at the deadline; neither reached engine
creation, schema initialization, or writes, and no child exception was queued.
A separate bounded-thread comparison showed the same import-readiness failure.
The underlying reason for slow imports was not established. These diagnostic
stacks were captured in reproductions, not in the original failed pytest workers.
The diagnostic
reporters exit 0 after saving evidence; that is **not** a passing regression.
See `final-offline/concurrency-diagnosis/summary.json` for commands and raw stacks.

## Reproduce

From the checkout, use a fresh evidence directory rather than overwriting a run:

```bash
UV_CACHE_DIR=/tmp/maverick-e2e-uv-cache uv sync --frozen --extra dev --extra backtesting --extra research
RUN_DIR=$(mktemp -d /tmp/maverick-e2e-reproduce-XXXXXX)
.venv/bin/python tests/e2e/protocol_checks.py --evidence-dir "$RUN_DIR/protocol"
.venv/bin/python tests/e2e/core_checks.py --evidence "$RUN_DIR/core"
.venv/bin/python tests/e2e/optional_checks.py --output "$RUN_DIR/optional"
.venv/bin/python tests/e2e/application_client.py --output "$RUN_DIR/application"
.venv/bin/python tests/e2e/live_checks.py --output "$RUN_DIR/yahoo"
.venv/bin/python tests/e2e/build_matrix.py --core-dir "$RUN_DIR/core" --optional-dir "$RUN_DIR/optional" --protocol-dir "$RUN_DIR/protocol" --application-dir "$RUN_DIR/application" --output "$RUN_DIR/matrix"
UV_NO_SYNC=1 make lint typecheck docs-check
env -u HTTP_PROXY -u HTTPS_PROXY -u ALL_PROXY -u OPENAI_PROXY \
  -u http_proxy -u https_proxy -u all_proxy -u openai_proxy \
  LANGSMITH_TRACING=false LANGCHAIN_TRACING_V2=false \
  uv run --frozen --extra dev --extra backtesting --extra research pytest --timeout=60
```

Local socket access is required. The first four scripts need no paid credentials.
The last live command uses only ordinary Yahoo requests. Paid mode must be
explicitly authorized for a new run; it is never part of pytest or a default
script invocation. Do not reuse a zero reservation for an ongoing authorization.
