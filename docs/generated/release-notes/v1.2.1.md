## maverick-mcp-server v1.2.1

Published by the tag-triggered workflow: the GHCR image
`ghcr.io/wshobson/maverick-mcp:1.2.1`, now for both `linux/amd64` and
`linux/arm64`. PyPI and the official MCP Registry are still pending: the PyPI
name `maverick-mcp-server` is held by a dormant, unrelated project, and a
PEP 541 name-transfer request is open with PyPI. Do not install
`maverick-mcp-server` from PyPI until the README says the name is ours;
install from the release tag or run the image instead.

### Fixes

- **Server version.** MCP clients now see the server's own version in
  `serverInfo` (`1.2.1`). Earlier releases reported FastMCP's version (#322).
- **arm64 image.** The image is published for `linux/arm64` as well as
  `linux/amd64`, so Apple Silicon and ARM Linux hosts run it natively instead
  of under emulation (#322).
- **PostgreSQL URLs under SQLAlchemy 2.1.** SQLAlchemy 2.1 loads psycopg 3
  for a plain `postgresql://` URL, and this project installs psycopg2. Such a
  URL is now pinned to `postgresql+psycopg2://`, so existing `DATABASE_URL`
  values keep working. Explicit `postgresql+<driver>://` URLs are unchanged
  (#323).

### Dependencies

Every locked dependency was upgraded to its latest compatible release (#320,
#323). Version floors are unchanged. Notable moves:

- fastmcp 4.1.0, mcp 2.3.0, starlette 1.8.0, uvicorn 0.54.0
- SQLAlchemy 2.1.5, pydantic 2.14.1, pydantic-settings 2.16.0
- openai 3.34.0, anthropic 1.15.0, langchain-core 1.6.12,
  langchain-openai 1.7.2, langgraph 1.2.16, langsmith 0.14.11, exa-py 2.25.0
- numpy 2.5.4, numba 0.68.0, vectorbt 1.1.2, scikit-learn 1.9.1,
  scipy 1.18.1, yfinance 1.7.0

### Install

```bash
# Run the release tag straight from GitHub (add extras with
# "maverick-mcp-server[backtesting,research] @ git+...")
uvx --from "git+https://github.com/wshobson/maverick-mcp@v1.2.1" maverick-mcp --transport stdio

# Or the image: Streamable HTTP on port 8000 inside the container
docker run --rm -p 127.0.0.1:8003:8000 \
  --mount source=maverick-data,target=/data \
  ghcr.io/wshobson/maverick-mcp:1.2.1
```
